### اجرای محلی در XAMPP ویندوز

در XAMPP، Apache را اجرا کنید و سایت را از `http://localhost/tisheh/` باز کنید؛ فایل `.htaccess` ریشه درخواست‌ها را به مسیر `public` هدایت می‌کند تا فهرست سورس پروژه و فایل‌های خصوصی از وب نمایش داده نشوند. برای نصب در این زیرپوشه، `APP_URL=http://localhost/tisheh/public` را در `.env` بگذارید تا پیوندهای داخلی نیز به مسیر درست بروند. برای نصب در ریشه دامنه، مقدار `APP_URL` باید URL همان دامنه باشد. ریشه وب Apache برای استقرار واقعی نیز باید خود پوشه `public` باشد. اگر `php -v` نسخه‌ای پایین‌تر از 8.2 نشان می‌دهد، فرمان‌های Artisan را با PHP همراه XAMPP اجرا کنید:

```powershell
cd C:\xampp8.2\htdocs\tisheh
& 'C:\xampp8.2\php\php.exe' artisan route:list
```

```bash
cd tisheh
composer install
cp .env.example .env
php artisan key:generate
```

دیتابیس UTF-8 و کاربر اختصاصی بسازید و متغیرهای `DB_CONNECTION=mysql`، `DB_HOST`، `DB_DATABASE`، `DB_USERNAME` و `DB_PASSWORD` را در `.env` تنظیم کنید. رمز واقعی در Git قرار نگیرد.

```bash
php artisan migrate --seed
php artisan storage:link
php artisan tisheh:admin
php artisan serve --host=0.0.0.0 --port=8000
```

`storage:link` برای نمایش تصاویر ضروری است. npm برای اجرای وب لازم نیست؛ تنها آزمون مرورگر به آن نیاز دارد. DatabaseSeeder نقش/دسته/کشور و صفحات help/about را می‌سازد، نه حساب نمونه یا پول نمایشی.

Migration شماره 000005 ستون deadline/پذیرش مبلغ و actor سیستمی اضافه می‌کند. Migration شماره 000004 نیز جدول چالش OTP و تلاش‌های پرداخت دمو را اضافه می‌کند؛ هیچ رکورد قدیمی به paid تبدیل نمی‌شود.

در اجرای این تحویل روی PHP 8.2.12 و SQLite، **۱۳۸ تست با ۵۹۴ assertion موفق** بودند. گزارش‌های آرشیوی نسخه قبلی `docs/test-sqlite.txt` و `docs/test-mysql-driver.txt` شامل ۱۲۷ تست/۵۰۹ assertion هستند و پس از این تغییرات دوباره روی MariaDB اجرا نشده‌اند.

آزمون مرورگر Chromium: هر ۱۳ مسیر ادمین، صفحات عمومی و پنل‌ها؛ نبود بیرون‌زدگی افقی در عرض ۳۹۰/۷۶۸/۱۴۴۰؛ نبود تصویر شکسته؛ گفتگوی دوطرفه؛ رد خواندن توسط شخص ثالث؛ سفارش تا تحویل با پرداخت تأییدنشده؛ پاسخ ادمین به گزارش و اعلان؛ بدون خطای JavaScript در گردش آزموده‌شده.

`tests/Browser/e2e.cjs` فقط روی محیط disposable دارای DemoSeeder و رضایت `TISHEH_E2E_ALLOW_WRITE=1` اجرا شود؛ فایل رمز از `TISHEH_CREDENTIALS` و URL از `TISHEH_BASE_URL` دریافت می‌شود. این تست عمداً داده آزمون و سفارش ایجاد می‌کند و پاک‌سازی خودکار ندارد. برای گردش جدید `npm run test:browser:demo` با همان متغیرهای رضایت/حساب اجرا می‌شود. جزئیات در docs/TESTING.fa.md است.

موفقیت تست، تضمین آمادگی تولید نیست. تست چند اتصال واقعاً همزمان، بار/نفوذ، MySQL 8 مستقل، Android و خدمات مالی بیرونی انجام نشده‌اند.

## ۶. بخش‌های هنوز تحویل‌نشده

- ارسال واقعی SMS، ورود OTP تولیدی و بازیابی خودکار و احراز هویت حرفه‌ای؛ فرم چهاررقمی و ورود دمو اکنون موجود است.
- درگاه بانکی واقعی (فرم و گردش دمو موجود است)، کیف پول، دستمزد، برداشت، دفترکل مالی، رسید بانکی، تسویه و بازپرداخت؛ نیازمند بررسی حقوقی و provider مجاز.
- اعمال واقعی هزینه انتشار/اشتراک، تبلیغات و گزارش درآمد وصول‌شده؛ تنظیم مبلغ به‌تنهایی این قابلیت‌ها را فعال نمی‌کند.
- ویرایش نقش/مجوز و ساخت مدیر از UI؛ ماتریس فعلی فقط‌خواندنی است.
- موقعیت جغرافیایی معتبر/فاصله، دایرکتوری نیروها و امتیاز/نظر مبتنی بر سابقه معتبر، نقشه تعاملی و نمونه‌کار عمومی.
- تصاویر پروژه، بازگشایی رسمی درخواست و نمونه‌کار حرفه‌ای. حذف تصویر محصول، فیلتر بازه تاریخ/دستمزد و مرحله بررسی ادمین اکنون موجودند.
- پیام‌رسان بلادرنگ، فایل پیام، Push، MFA مدیر، سیاست نهایی حذف/نگهداری داده و ممیزی مستقل.
- نسخه عربی/عراق و ضوابط حقوقی و پرداخت آن کشور.
- Android WebView، APK آزمایشی و APK release امضاشده. دامنه HTTPS نهایی و کلید امضای کارفرما هنوز لازم‌اند.
