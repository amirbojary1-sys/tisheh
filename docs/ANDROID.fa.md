# برنامه مرحله هشتم Android — بدون APK در این تحویل

در r0.1 سورس Android یا APK ارائه نشده است. بسته‌بندی صفحه وب بدون تکمیل backend، آزمون واقعی و دامنه HTTPS نباید به‌عنوان اپلیکیشن نهایی معرفی شود.

## ورودی‌های لازم

- دامنه HTTPS نهایی و آدرس staging؛ مالکیت دامنه و تنظیم allowlist لینک‌ها.
- نام package نهایی مانند `com.tisheh.app` با تأیید مالک برند.
- سیاست حریم خصوصی، نسخه‌های SDK هدف بر اساس الزامات زمان انتشار و کانال توزیع.
- keystore تحت مالکیت کارفرما، alias و فرآیند نگهداری امن؛ رمز امضا وارد Git نشود.
- برای Push، ارائه‌دهنده منتخب و سیاست token/device و رضایت اعلان لازم است.

## الزامات پروژه واقعی

- Kotlin یا Java با WebView استاندارد و BuildConfig مجزا برای staging/release.
- اینترنت تنها مجوز پیش‌فرض. از مجوزهای حافظه گسترده یا دسترسی تمام فایل‌ها استفاده نشود.
- HTTPS الزامی؛ `usesCleartextTraffic=false`؛ هیچ `SslErrorHandler.proceed()` مجاز نباشد.
- JavaScript فقط به اندازه نیاز فرم‌ها؛ bridge بومی غیرضروری ایجاد نشود. `file://`، mixed content و universal file access غیرفعال.
- URL اولیه و redirectها با scheme/host/port معتبر بررسی شوند. ناوبری داخلی فقط در origin مجاز، لینک‌های خارجی با Intent امن و allowlist scheme؛ لینک‌های ناشناس مسدود.
- `tel:`، نقشه و درگاه خارج از WebView طبق جریان موردتأیید؛ نبود اپ مقصد بدون crash مدیریت شود.
- فایل‌گزین از `ACTION_OPEN_DOCUMENT` و URI grant محدود استفاده کند. دوربین با رضایت، FileProvider و URI موقت؛ بدون file URI عمومی.
- cancellation انتخاب فایل و lifecycle callback درست پاک شود. MIME و حجم همچنان در backend اعتبارسنجی شوند؛ اعتماد به WebView کافی نیست.
- صفحه خطای اینترنت با تلاش دوباره، progress indicator، نمایش دامنه و دکمه بازگشت مبتنی بر history؛ از reloadهای بی‌پایان پرهیز شود.
- کوکی و نشست مطابق سیاست امنیت وب؛ token در JavaScript یا localStorage به‌عنوان جایگزین نشست امن ذخیره نشود.
- رنگ‌های اصلی مشکی و طلایی، آیکون تیشه و splash سازگار با نسخه‌های جدید Android.

## خروجی‌های لازم در همان مرحله

۱. سورس کامل Android با Gradle Wrapper و نسخه وابستگی‌های قفل‌شده.
۲. debug APK متصل به staging واقعی و گزارش آزمون دستگاه.
۳. release APK امضاشده با کلید مالک، شماره نسخه، checksum SHA-256 و دستور build مجدد.
۴. راهنمای بازتولید امضا و نگهداری keystore؛ کلید خصوصی جدا از بسته عمومی سورس.
۵. آزمون upload، تصویر دوربین، لغو انتخاب، قطع شبکه، back، session expiry، لینک داخلی/خارجی و مسیر واقعی درگاه پس از اتصال.

هیچ‌یک از این artifactها در نسخه حاضر تولید نشده‌اند و ساخت یا انتشار موفق آنها ادعا نمی‌شود.
