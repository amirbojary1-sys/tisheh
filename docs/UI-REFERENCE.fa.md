# بازطراحی بر اساس تصاویر کارفرما

زبان بصری تصاویر مرجع به وب واقعی منتقل شد، نه اینکه تصاویر کامل به‌عنوان صفحه کلیک‌ناپذیر استفاده شوند.

- زمینه مشکی، سطوح بسیار تیره، خط دور ظریف، طلایی گرم و متن سفید/خاکستری.
- لوگوی تیشه با ترکیب کلاه ایمنی و ابزار، نام فارسی و زیرنویس ثابت برند.
- صفحه اصلی اپلیکیشنی با بنر ساخت‌وساز، دو مسیر کارفرما/کارگر، بازار و فروش مصالح، دسته‌های تخصصی و کارت‌های فشرده.
- منوی پایین پنج‌تایی: خانه، درخواست‌ها، اقدام مرکزی، پیام‌ها، پروفایل. اقدام مرکزی بر اساس نقش واقعاً به مسیر مجاز می‌رود؛ برای کارگر جستجوی کار است، نه انتشار کارفرما.
- فرم‌ها، گفتگو، اعلان، پیگیری درخواست و سفارش با کارت تیره و دکمه طلایی گرد.
- پنل ادمین مستقل: سایدبار دسکتاپ، هدر کاربر، کارت شاخص، نمودار واقعی و جدول/فیلتر؛ موبایل بدون بیرون‌زدگی و ناوبری افقی قابل اسکرول.

بخش سفید برخی تصاویر به‌دلیل اصل ثابت برند، تیره نگه داشته شد. عکس افراد، نشان احراز، امتیاز، فاصله، آنلاین‌بودن، مبلغ کیف پول و موفقیت پرداخت بدون داده معتبر تقلید نشدند. نقشه تعاملی و درگاه کارت بانکی تصویر مرجع بدون اتصال واقعی پیاده‌سازی/نمایش داده نشدند. سربرگ و تصاویر تزئینی/شماتیک با واقعیت پروژه یا هویت افراد اشتباه معرفی نمی‌شوند.

سبک‌های نهایی در public/css/reference.css و توکن‌های مرکزی در ابتدای آن هستند؛ Blade مشترک باعث یکپارچگی صفحات وب و پنل‌ها می‌شود.
