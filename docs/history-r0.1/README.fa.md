# تیشه | TISHEH
## تحویل توسعه r0.1 — زیرساخت واقعی و مسیرهای اولیه کاریابی و مصالح

**تاریخ تحویل: ۲۴ اکتبر ۲۰۲۶**

این بسته، نسخه نهایی همه هشت مرحله نیست. زیرساخت مرحله اول و یک برش قابل آزمون از پنل‌های کاربری، کاریابی، مصالح و مدیریت پیاده‌سازی شده است. این نسخه به دیتابیس متصل است؛ صفحات اصلی از داده زنده خوانده می‌شوند و فرم‌ها عملیات واقعی انجام می‌دهند. **سفارش، پرداخت، کیف پول، پیامک، پیام‌رسان، اعلان و APK هنوز پیاده‌سازی نشده‌اند.**

> آگهی‌ها، قیمت‌ها، موجودی‌ها، کاربران و تصاویر شماتیک اولیه، داده آزمایشی هستند؛ پیشنهاد کار یا فروش واقعی نیستند. هیچ موجودی پولی، پرداخت موفق یا رسید بانکی ساختگی نمایش داده نمی‌شود. تصویر سربرگ با هوش مصنوعی و تصاویر مصالح به‌صورت شماتیک تولید شده‌اند.

### فناوری و وضعیت اجرا

- PHP 8.4.27؛ Laravel **12.70.1** با محدودیت نسخه `^12.0` در Composer.
- Blade، CSS، JavaScript؛ بدون React، سرویس جایگزین Node یا دیتابیس در حافظه مرورگر.
- اتصال واقعی `mysql` در Laravel. دیتابیس پیش‌نمایش و تست دوم: **MariaDB 11.8.6**؛ MySQL 8 مستقل در این محیط اجرا نشده است.
- Migrationها از Schema Builder استاندارد Laravel استفاده می‌کنند. فایل اختیاری `compose.mysql.yaml` برای MySQL 8.4 ارائه شده، اما این پیکربندی Docker در این محیط اجرا نشده است.
- CSS و JavaScript در `public/css/app.css` و `public/js/app.js` هستند؛ اجرای سایت به npm یا CDN نیاز ندارد.
- فونت Vazirmatn به‌صورت محلی با مجوز OFL در `public/fonts/OFL.txt` موجود است.

## امکانات واقعاً قابل استفاده

### حساب و دسترسی

- ثبت‌نام نقش‌های کارگر/استادکار، کارفرما/پیمانکار و فروشنده؛ ثبت‌نام عمومی مدیر ممنوع است.
- نام، نام خانوادگی، شماره موبایل ایران و شهر اجباری؛ تخصص برای کارگر و نام و آدرس فروشگاه برای فروشنده اجباری است.
- نرمال‌سازی ارقام فارسی موبایل و فیلدهای عددی، جلوگیری از موبایل تکراری، هش رمز، ورود با موبایل و رمز، خروج POST و بازتولید شناسه نشست.
- اعتبارسنجی سمت سرور، خطاهای فارسی در فرم‌های اصلی، حفظ اطلاعات غیرحساس پس از خطا؛ رمزها دوباره نمایش داده نمی‌شوند.
- پنل اختصاصی متناسب با نقش؛ ویرایش نام، نام خانوادگی، شهر و معرفی کوتاه.
- نقش‌ها و مجوزها در دیتابیس، Middleware برای مجوزهای ماژول و Policy برای مالکیت رکوردها.
- موبایل کاربران جدید **تأییدنشده** است. OTP متصل نیست و هیچ تأیید کاذبی ثبت نمی‌شود.

### کاریابی

- ثبت و ویرایش درخواست کار با عنوان، تخصص، تعداد، مهارت، شرح، شهر، آدرس خصوصی، تاریخ شروع، مدت، دستمزد و دوره پرداخت.
- ذخیره پیش‌نویس یا ارسال برای بررسی؛ انتشار فقط با تأیید مدیر.
- جستجوی عنوان و شهر، فیلتر تخصص، مرتب‌سازی جدیدترین/دستمزد؛ API داخلی فیلتر حداقل دستمزد را نیز می‌پذیرد.
- اعلام آمادگی واقعی کارگر؛ جلوگیری از تکرار با قفل تراکنشی و قید یکتا.
- مشاهده متقاضیان و پذیرش/رد توسط کارفرمای صاحب درخواست؛ پیگیری در پنل کارگر.
- تکمیل یا لغو درخواست توسط مالک. آدرس دقیق پروژه در صفحه عمومی نشان داده نمی‌شود.
- تماس موبایلی برای کاربران واردشده؛ صلاحیت یا مالکیت موبایل تضمین‌شده نیست.

### مصالح

- ثبت و ویرایش آگهی فروش، برند، مشخصات، واحد، قیمت، موجودی، حداقل سفارش، حمل و شرایط فروش.
- ذخیره پیش‌نویس، بررسی مدیر، انتشار و غیرفعال‌کردن توسط مالک.
- آپلود تصویر واقعی JPG/PNG/WebP تا ۴ مگابایت و حداکثر ۴۰۹۶ پیکسل در هر ضلع؛ بازرمزگذاری به WebP برای حذف متادیتا و محتوای ضمیمه. SVG آپلودی پذیرفته نمی‌شود.
- جستجوی نام، برند و شهر، فیلتر دسته و مرتب‌سازی قیمت، برند، موجودی، تاریخ یا قیمت یک واحد به‌همراه حمل اعلامی.
- مقایسه ۲ تا ۴ محصول از یک صفحه؛ نمایش مشخصات، برند، واحد، قیمت، حمل، موجودی و حداقل سفارش.
- هشدار در مقایسه دسته یا واحد متفاوت؛ حمل نامعلوم «صفر» نیست. مقایسه به معنی تضمین برابری کیفیت نیست.
- نمایش آدرس عمومی فروشگاه، تماس و جستجوی آدرس روی Google Maps با کلیک کاربر. موقعیت دقیق یا فاصله تأییدشده ادعا نمی‌شود.
- مبلغ در دیتابیس **ریال** است؛ نمایش **تومان** با حفظ دهم تومان انجام می‌شود.

### مدیریت و امنیت اولیه

- مسیر مستقل `/admin` و قالب مشترک برند به‌همراه قالب مدیریت جداگانه.
- آمار واقعی کاربران/درخواست‌ها/مصالح، بررسی آگهی‌ها، دلیل رد، مسدودسازی و فعال‌سازی کاربران غیرمدیر.
- مسدودکردن خود و مدیران دیگر از این رابط ممکن نیست؛ نشست‌های کاربر مسدودشده حذف می‌شوند.
- لاگ فعالیت‌های اصلی و مدیریتی؛ مدل لاگ اجازه ویرایش و حذف نمی‌دهد. این ویژگی جایگزین لاگ مستقل و غیرقابل‌تغییر زیرساخت نیست.
- CSRF، خروجی escape‌شده Blade، Eloquent، محدودیت تلاش ورود و عملیات نوشتنی، کوکی HttpOnly، رمزنگاری نشست و هدرهای امنیتی.
- مدیریت پول یا رکورد مالی در رابط مدیریت وجود ندارد.

## نصب محلی

### پیش‌نیازها

PHP 8.2 یا بالاتر، Composer 2، MySQL 8 یا MariaDB سازگار، افزونه‌های PDO MySQL، mbstring، XML/DOM، ctype، fileinfo، openssl، tokenizer و **GD با WebP**. برای تست سریع SQLite، افزونه `pdo_sqlite` نیز لازم است. نصب وابستگی‌ها اینترنت می‌خواهد؛ خود صفحات سایت CDN مصرف نمی‌کنند.

```bash
cd tisheh
composer install
cp .env.example .env
php artisan key:generate
```

یک دیتابیس خالی UTF-8 و کاربر اختصاصی بسازید. مقادیر زیر را در `.env` تنظیم کنید؛ رمز واقعی را وارد مخزن نکنید:

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=tisheh
DB_USERNAME=tisheh
DB_PASSWORD=YOUR_LOCAL_DATABASE_PASSWORD
```

در صورت استفاده از Docker فقط برای دیتابیس، پس از تعیین `DB_ROOT_PASSWORD`:

```bash
docker compose -f compose.mysql.yaml up -d
```

سپس:

```bash
php artisan migrate --seed
php artisan storage:link
php artisan tisheh:admin
php artisan serve --host=0.0.0.0 --port=8000
```

نشانی محلی: `http://localhost:8000`. ساختار دیتابیس را با Migration بسازید؛ فایل `docs/schema-reference.sql` مرجع خروجی محیط آزمایش است، نه جایگزین Migration.

### ساخت مدیر اولیه

`php artisan tisheh:admin` نام و موبایل مدیر را می‌پرسد و رمز حداقل ۱۲ نویسه‌ای با حروف بزرگ، کوچک و عدد را به‌صورت مخفی دریافت می‌کند. **در سورس، حساب یا رمز پیش‌فرض مدیر وجود ندارد.** ابتدا `migrate --seed` را اجرا کنید تا نقش مدیر ساخته شود. ایجاد مدیر به معنی تأیید مالکیت موبایل نیست.

بازیابی اضطراری از سمت اپراتور سرور:

```bash
php artisan tisheh:reset-password
```

این ابزار تنها پس از احراز مالکیت خارج از سامانه و تأیید صریح اپراتور استفاده شود. همه نشست‌ها را باطل و رویداد را ثبت می‌کند؛ جایگزین بازیابی عمومی پیامکی نیست.

### داده نمونه، فقط توسعه

```bash
# فقط APP_ENV=local یا testing؛ در production عمداً رد می‌شود
php artisan db:seed --class=DemoSeeder
```

در اولین اجرا برای چهار نقش، رمزهای تصادفی چاپ می‌شوند. آنها را خصوصی نگه دارید؛ اجرای دوباره رمز حساب‌های موجود را چاپ یا عوض نمی‌کند. شماره‌های نمونه و قیمت‌ها واقعی نیستند. در سرور تجاری DemoSeeder اجرا نشود.

## آزمون و نتیجه تحویل

```bash
php artisan test
vendor/bin/pint --test
composer audit
```

- نتیجه: **۳۹ تست، ۱۲۶ assertion؛ همگی موفق** روی SQLite و مجدداً روی MariaDB با درایور `mysql`.
- آزمون مرورگر Chromium: ورود نقش‌ها، ثبت درخواست، انتشار مدیر، اعلام آمادگی و پذیرش، ثبت و انتشار مصالح، مقایسه، ثبت‌نام واقعی و رد درخواست بدون CSRF انجام شد.
- کنترل عدم اسکرول افقی در عرض‌های ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل برای خانه، کاریابی، مصالح و ثبت‌نام؛ بدون خطای JavaScript در گردش آزموده‌شده.
- Composer audit در زمان تحویل آسیب‌پذیری شناخته‌شده گزارش نکرد. این معادل ممیزی مستقل امنیتی نیست.
- این تست‌ها شامل بار واقعی، درگاه، پیامک، دستگاه اندروید، MySQL مستقل، رقابت چند اتصال همزمان و تست نفوذ نیستند.

برای تست MySQL از دیتابیس **مستقل و خالی تست** استفاده کنید. `RefreshDatabase` ممکن است جداول آن را حذف کند:

```bash
# این متغیرها را در نشست خصوصی تنظیم کنید؛ هرگز به دیتابیس production اشاره نکنند
export DB_CONNECTION=mysql
export DB_DATABASE=tisheh_test
export DB_USERNAME=YOUR_TEST_USER
read -s DB_PASSWORD; export DB_PASSWORD
php artisan test
```

روش اجرای تست مرورگر در `docs/TESTING.fa.md` آمده است. گزارش‌های خام در `docs/test-*.txt` قرار دارند.

## بخش‌های عمداً تحویل‌نشده

- OTP، بازیابی خودکار پیامکی و تأیید هویت حرفه‌ای؛ نیازمند انتخاب سرویس معتبر.
- پیام‌رسان، اعلان درون‌برنامه‌ای/پوش، گزارش تخلف و شکایت، امتیاز و نظر.
- سفارش و رزرو موجودی، پرداخت مستقیم با ثبت نتیجه، درگاه، رسید، بازپرداخت و پیگیری سفارش.
- کیف پول، دفترکل مالی، دستمزد، برداشت، اشتراک و درآمد تیشه. هیچ جدول یا داده مالی ناقصی به‌عنوان زیرساخت پول واقعی معرفی نشده است.
- مدیریت جامع نقش‌ها، دسته‌بندی‌ها، محتوا، تنظیمات، درآمد و گزارش‌های مالی از پنل.
- فیلتر بازه تاریخ/حداکثر دستمزد در رابط، تصاویر پروژه، نمایش نزدیک‌ترین فروشگاه و فاصله جغرافیایی.
- ویرایش تخصص و مشخصات فروشگاه، حذف تصاویر قبلی از پنل؛ تصاویر جدید در ویرایش به گالری اضافه می‌شوند.
- ترجمه عربی، شماره موبایل عراق، فعال‌سازی پرداخت یا فعالیت حقوقی در عراق.
- سورس Android، APK آزمایشی و APK نهایی امضاشده؛ این‌ها مربوط به مرحله هشتم هستند و در این بسته موجود نیستند.
