# TISHEH | تیشه — r0.2

**راهنمای کامل فارسی: [README.fa.md](README.fa.md)**

Laravel 12 / Blade construction jobs and materials marketplace. This release includes a reference-inspired black-and-gold app UI, dedicated administration, direct material orders with transactional inventory reservation, private two-party messaging, database notifications, support reports and 72 feature tests.

No bank gateway, wallet, wage payout, SMS verification or Android APK is enabled or delivered. Order references are not payment receipts. Role permission editing is intentionally read-only.

Install with Composer, configure a private `.env`, migrate/seed, create the storage link and create your first administrator via `php artisan tisheh:admin`. See the Persian guide for full scope, upgrade and testing instructions.
